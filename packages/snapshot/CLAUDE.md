# packages/snapshot — `shaar_hayichud_snapshot`

A pub.dev package whose content is a copy of `data/dist/v1` (catalog,
chapters, chapter alignments, `snapshot.txt`) declared as Flutter assets, so
apps (lessons2) bundle it and work offline on first launch. Pure Dart, no
dependencies; Flutter bundles a dependency's declared assets without it
depending on Flutter.

- `data/` is generated by `tool/build_snapshot.dart` and git-ignored;
  `.pubignore` replaces `.gitignore` for publishing, so it ships. Never commit
  it.
- The `version:` in `pubspec.yaml` is a placeholder. The publish workflow
  (`.github/workflows/publish-snapshot.yml`) sets it from the pushed tag
  `shaar_hayichud_snapshot-v1.<YYYYMMDD>.<n>`. Major = `/data/v1` schema
  version.
- The asset list in `pubspec.yaml` and `snapshotFiles` in
  `lib/shaar_hayichud_snapshot.dart` must match (a test checks it). Adding
  a kind of file is additive; removing or moving one breaks apps that load it,
  so it needs a major version.

Checks (after `yarn build-data` and `dart run tool/build_snapshot.dart`):
`dart analyze`, `dart test`.
