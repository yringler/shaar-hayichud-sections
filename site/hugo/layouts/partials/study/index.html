{{- /* The public study guides (data/dist/v1/study/index.json, the assets mount of data/dist/v1) and their pages: the one place that builds study URLs. Call with partialCached "study/index.html" . "study". Only the public edition is read: data/dist/study-beta is mounted under static/ alone, so no template can read it (see hugo.toml). Returns dict "series": slice, index order, of dict "id" (study series id, the URL slug) "title" "teacher" "catalogSeriesId" "url" (/study//) "chapters" (slice of chapter entries) "chapters": chapter key -> slice of chapter entries (one per series with a guide for that chapter, in series order) "lectures": catalog lecture id -> slice of dict "chapter" "number" "page" (the guide) "url" (the guide with ?class=) "series" (the series dict above, without "chapters"), one per guide that cites it A chapter entry is dict "chapter" (key) "number" (string, no leading zero) "url" (/study//chapter-N/) "path" (asset path of the guide, data/v1/…) "status" "stale" (bool) "lectures" (the index's lectures: id, start, end, continuesIn?) "series" (as above, without "chapters") "teacher". A lecture's slug is its transcript page slug (partials/audio/index.html): the id lowercased, extension dropped, other runs of characters -> "-". Fails the build when the index is missing, on a series id that is not a plain slug, and on two series or two chapters with the same URL. */ -}} {{- $ix := resources.Get "data/v1/study/index.json" -}} {{- if not $ix -}} {{- errorf "study index missing under data/dist/v1 (data/v1/study/index.json): run the data build first (yarn build / yarn data in site/)" -}} {{- end -}} {{- $s := newScratch -}} `^[a-z0-9]+(-[a-z0-9]+)*$` $series.id 1) -}} {{- errorf "study: series id %q is not a URL slug (lowercase letters, digits and single dashes)" $series.id -}} {{- end -}} {{- $seriesUrl := printf "/study/%s/" $series.id -}} {{- with $urls.Get $seriesUrl }}{{ errorf "study: two series have the URL %s" $seriesUrl }}{{ end -}} {{- $urls.Set $seriesUrl true -}} {{- $info := dict "id" $series.id "title" $series.title "teacher" $series.teacher "catalogSeriesId" $series.catalogSeriesId "url" $seriesUrl -}} {{- $chapters := slice -}} {{- range $c := $series.chapters -}} {{- $n := replaceRE `^chapter_0*` "" $c.chapter -}} {{- $url := printf "%schapter-%s/" $seriesUrl $n -}} {{- with $urls.Get $url }}{{ errorf "study: two guides of %q have the URL %s" $series.id $url }}{{ end -}} {{- $urls.Set $url true -}} {{- if not (hasPrefix $c.path (printf "study/%s/" $series.id)) -}} {{- errorf "study: guide path %q is not under study/%s/" $c.path $series.id -}} {{- end -}} {{- $entry := dict "chapter" $c.chapter "number" $n "url" $url "path" (printf "data/v1/%s" $c.path) "status" $c.status "stale" ($c.stale | default false) "lectures" $c.lectures "series" $info "teacher" $series.teacher -}} {{- $chapters = $chapters | append $entry -}} {{- $prev := (index ($s.Get "chapters") $c.chapter) | default slice -}} {{- $s.SetInMap "chapters" $c.chapter ($prev | append $entry) $info)) -}} {{- end -}} {{- end -}} {{- $s.Add "series" (slice (dict "id" $series.id "title" $series.title "teacher" $series.teacher "catalogSeriesId" $series.catalogSeriesId "url" $seriesUrl "chapters" $chapters)) -}} {{- end -}} {{- return dict "series" ($s.Get "series") "chapters" ($s.Get "chapters") "lectures" ($s.Get "lectures") -}}
